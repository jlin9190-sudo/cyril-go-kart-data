# RaceBobo VBO

本仓库的原始文件是 RaceBobo（[carrot.racebobo.cn](https://carrot.racebobo.cn)）导出的 VBO。下面是 2026-10-17 佛山 P1 两场文件里实际看到的格式。

## 采样 / Sample rate

- **25 Hz**。文件头注释为 `Log Rate (Hz) : 25.00`。
- `[comments]` 同时给出 `Beijing Time` 与 `UTC`。
- 数据列 `time` 是 UTC 的 `HHMMSS.sss`（例如 `071738.040`）。

## 经纬度 / Latitude and longitude

列名是 `lat` 和 `long`，单位是**分**（arcminutes），不是度。

```
lat_deg = lat / 60
lon_deg = -long / 60
```

东经在文件里存成**负数**。例如 `long = -06795.94802`（分），`lon_deg = -long / 60 ≈ 113.266`。

## 列 / Columns

`[column names]`：

```
sats time lat long velocity heading height vertvel rpm event1
```

| 列 | 含义 |
| --- | --- |
| `sats` | 卫星数 |
| `velocity` | km/h |
| `heading` | 航向，度 |
| `height` | 高程，米 |
| `vertvel` | 垂直速度，km/h |
| `rpm` | 通道存在，但这两场全是 `00000`。没有可用 RPM。 |
| `event1` | 触发计数；这两场未见有效圈计时事件 |

## 没有 `[laptiming]`

这两场只有 `[header]`、`[channel units]`、`[comments]`、`[column names]`、`[data]`，**没有** `[laptiming]`。圈界要用计时线过线自己切，或对照场地公布的最快圈。

## 文件头示例 / Header notes

`[comments]` 里常见：

```
Generated by Racebobo
Generated from PVT data v1.1
Track: 佛山P1国际赛车场
Beijing Time: 2026-10-17 15:17:37
UTC: 2026-10-17T07:17:38.040Z
Log Rate (Hz) : 25.00
```
